# LibriVault - Library Catalogue

LibriVault is a responsive web-based library catalogue that allows users to browse, search and filter a collection of books.

## Features

- Responsive library catalogue interface
- Dynamic rendering of books using JavaScript
- Search books by title or author
- Case-insensitive search
- Filter books by category
- Display all books option
- Add and remove books from favourites
- Visual favourite indicators
- Book availability indicators
- Visual distinction for unavailable books
- Empty and no-results states
- Mobile-friendly layout

## Technologies

The system was developed using:

- HTML5
- CSS3
- JavaScript
- Git

- GitHub Pages
